VOID-NAV · hardware build 1 · one ESP32, two LoRa radios

VOID-NAV Wiring Guide

Wire one ESP32 to both RA-02 LoRa radios, two LEDs and a button. Then load the code and send your first SOS from a phone. No experience needed: follow the steps in order.

📱 PhoneWi-Fi →ESP32→Radio A~ 433 MHz air ~Radio B→ USB →💻 Laptop

Radio A acts as the survivor's node and radio B as the rescue command's receiver. The message really flies through the air between the two antennas. Both radios share one ESP32 for now. When a second ESP32 arrives, each radio gets its own board.

Before you touch anything

Four rules that keep parts alive

Unplug the USB while wiringOnly plug the ESP32 in after every wire is placed and checked.
LoRa gets 3.3 V, never 5 VUse the pin labelled 3V3. The pins called VIN or 5V will burn the radio.
Antenna on firstNever power a LoRa radio without its antenna attached. Sending without one can damage it.
No loose metalBare wire ends must never touch each other or the table. Push each wire in firmly.

Check this first

What does your LoRa radio look like?

On a small board with pins ✅

You see a row of metal pins with labels such as NSS, SCK and 3.3V. Push female jumper ends straight onto them. You're ready.

A bare silver square with tiny gold dents ⚠️

The RA-02 alone has 2 mm pads that don't fit jumper wires or the breadboard. You need an RA-02 adapter board, or short wires soldered onto the pads. Do this before anything else.

The RA-02's labels: 3.3V GND NSS (some boards say CS) SCK MISO MOSI RST (or RESET). It also has DIO0–DIO5, which we leave empty.

The big idea

The breadboard is a power strip for signals

Five wires are needed by both radios. A breadboard row of 5 holes is joined together inside, so one wire from the ESP32 and one wire to each radio meet in the same row. Make these five shared rows first:

3V3
GND
SCK
MISO
MOSI

Each row gets three wires: one from the ESP32, one to radio A, one to radio B. For GND you can use the long blue (−) rail on the side instead, because the LEDs and button need ground too. Many breadboards split that rail in the middle, so keep all GND wires on one half.

Small parts, explained

LEDs and the button

LED: which leg is which?

The long leg is plus (+) and goes to the ESP32 pin. The short leg is minus (−) and goes to ground. The rim of the LED is also flat on the minus side. Put the two legs in different breadboard rows, or the LED never lights.

We have no resistors, so the code limits the ESP32 pin to a gentle current. If you find a 220 Ω–1 kΩ resistor later, put it between the pin and the long leg.

Button: use opposite corners

The button has 4 legs. Plug it across the middle gap of the breadboard. Connect one corner to D13 and the diagonally opposite corner to ground. Opposite corners are always the pair that the press connects.

Software

Load the code

  1. Install Arduino IDE 2

    From arduino.cc/en/software. Open it once.

  2. Add ESP32 support

    Go to File → Preferences → Additional boards manager URLs and paste this link:

    https://espressif.github.io/arduino-esp32/package_esp32_index.json

    Then open Tools → Board → Boards Manager, search esp32, and install esp32 by Espressif Systems (3.x).

  3. Add the LoRa library

    Open Sketch → Include Library → Manage Libraries, search LoRa, and install LoRa by Sandeep Mistry.

  4. Open the sketch

    Open firmware/voidnav_esp32/voidnav_esp32.ino from the repo. Keep the folder name and the file name the same.

  5. Pick the board and port

    Choose Tools → Board → esp32 → ESP32 Dev Module. Plug in the USB cable, then pick the new entry under Tools → Port (COM3 on Windows, /dev/ttyUSB0 on Linux, /dev/cu.usbserial… on a Mac). If no port appears, try a different cable, because some cables only charge. You may also need the CP210x or CH340 driver.

  6. Upload

    Click the → arrow. If it stops at "Connecting…", hold the BOOT button on the ESP32 until the upload starts.

  7. Watch it start

    Open Tools → Serial Monitor and set it to 115200 baud. Press the EN (reset) button once. You should see:

    # Radio A (node) OK
# Radio B (gateway) OK
# Wi-Fi "VOID-NAV SOS" up, page at http://192.168.4.1
{"ev":"boot","role":"single","node":"3F2A","radioA":true,"radioB":true}
First test

Send your first SOS

  1. Spread the antennas

    Point the two antennas away from each other, at least a hand-length apart. The code makes the radios whisper because they are so close.

  2. Join the Wi-Fi from a phone

    Connect to VOID-NAV SOS, which has no password. A "Sign in to network" page should pop up. If it doesn't, open a browser and go to 192.168.4.1.

  3. Send

    Pick a type, type a message, and press SEND SOS. In the Serial Monitor a line starting with {"ev":"sos" appears. That message crossed the air from radio A to radio B. On the phone, step 2 "Reached rescue command" turns on.

  4. Act as the rescuer

    In the Serial Monitor's text box, type the commands below, using the ID from the sos line. Press Enter after each.

    READ 3F2A-517
DISPATCH 3F2A-517

    Each status travels back over LoRa to radio A. LED 1 lights up after READ, LED 2 after DISPATCH, and the phone page updates too.

  5. Try the button

    Press it once. A ready-made SOS is sent with no phone needed.

If something's wrong

Fixes for the usual problems

"Radio A not found" or "Radio B not found"

Unplug the USB first. Check that radio's NSS and RST wires (A: D5 and D4, B: D27 and D32). Then check that all five shared rows reach that radio. A wire in the wrong breadboard row is the most common cause. If only one radio fails, swap the radios to see whether the module or the wiring is at fault.

Both radios found, but no sos line appears

Check that both antennas are attached and the radios are on the same 433 MHz setting (both RA-02, so they are). Move the antennas further apart, since radios that are too close can deafen each other. Watch for "# TX A" lines: if the node keeps retrying, the message isn't arriving.

The upload fails

Hold BOOT during "Connecting…". Use a data USB cable. Close the Serial Monitor in other programs. If your 38-pin board resets in a loop, temporarily unplug the wire on D5.

No pop-up page on the phone

Turn off mobile data, then open 192.168.4.1 in the browser. Some phones say "no internet, stay connected?" Choose to stay connected.

An LED never lights

Turn the LED around: the long leg goes to the pin. Make sure its legs are in different rows, and that the short leg's rail really is ground.
